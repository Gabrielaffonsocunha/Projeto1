# Projeto1 — versão anterior dos protótipos de IA

Este repositório contém uma versão anterior dos protótipos de triagem de chamados e organização de reuniões.

A versão atual, com documentação principal e instruções de execução, está em [AI Builder Portfolio](https://github.com/Gabrielaffonsocunha/ai-builder-portfolio). Consulte esse repositório para acompanhar a versão mantida.

Os exemplos são educacionais e usam entradas fictícias. Não insira dados pessoais, internos ou confidenciais.
